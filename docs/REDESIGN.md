# Lista do redesignu interfejsu

Rzeczy, które trzeba uwzględnić przy zmianie wyglądu aplikacji (`apps/web`). Interfejs i zrzuty ekranu (`docs/screenshots/`) nie były zmieniane w fazie P7.

- [ ] **Stopka: „Powered by Etherscan.io APIs”** (z odnośnikiem do etherscan.io). Wymóg regulaminu darmowego planu Etherscan API (zob. `docs/research-notes.md`, „API i limity”): dane o transakcjach w sieci Ethereum pochodzą z tego źródła. Stopka ma być widoczna na każdej stronie aplikacji; tekst przez i18n (pl + en); bez ładowania czegokolwiek z zewnątrz (sam napis i zwykły odnośnik).
- [ ] Odświeżyć zrzuty ekranu w `docs/screenshots/` i tabelę „Przykłady” w `README.md` po zmianie wyglądu (wyłącznie z rzeczywistych przebiegów produktu, na danych syntetycznych).
